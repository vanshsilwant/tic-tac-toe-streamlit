# 🎮 Tic Tac Toe

A modern Tic Tac Toe game built using **Python**, **NumPy**, and **Streamlit**.

## 🚀 Features

- 🎮 Two Player Game
- ❌ X and ⭕ O Turns
- 🏆 Winner Detection
- 🤝 Draw Detection
- 📊 Live Scoreboard
- 🔄 Restart Game
- 🎨 Modern Streamlit UI

---

## 🛠 Tech Stack

- Python
- NumPy
- Streamlit

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/vanshsilwant/tic-tac-toe-streamlit.git
```

Move into the project folder:

```bash
cd tic-tac-toe-streamlit
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
streamlit run app.py
```
